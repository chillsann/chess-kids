# ♞ 国际象棋乐园

一个**纯前端、零依赖**的国际象棋网页游戏，一边玩一边学规则，适合新手和孩子。

## 玩法模式

| 模式 | 说明 |
| --- | --- |
| 和电脑玩 | 你执白，电脑执黑，可选**简单 / 中等 / 厉害**三档难度 |
| 和朋友一起玩 | 两人同屏轮流走棋 |

## 怎么操作

- 点一下自己的棋子 → 再点**绿色圆点**就能走；**粉色圈圈**表示这一步可以吃掉对方棋子
- **给个提示**：小助手推荐一步好棋
- **悔棋** / **翻转棋盘** / **新的一局**：随时可用
- 走路时右侧「小知识」会自动讲解这步棋的规则要点

## 支持的规则

- 王车易位（含「经过的格子被攻击就不能易位」的判定）
- 吃过路兵
- 兵升变（升到底线自动变皇后）
- 将军 / 将杀 / 逼和判定
- 三次重复局面判和、子力不足判和

## 声音

- **🎹 钢琴曲**：背景音乐是 Web Audio 实时合成的钢琴版《欢乐颂》（C 大调，16 小节循环，正弦泛音堆叠 + 琴槌噪声音色），不加载任何音频文件
- **🔊 音效**：走棋、吃子、将军、胜负等 11 种合成音效
- 两个开关的状态会记住；iPad / iPhone 侧边静音拨杆会关掉整个网页音频，页面里也有对应提示

## 本地打开

直接双击 `index.html` 就行，**不需要服务器、不需要安装任何东西**。

## 部署到 GitHub Pages

1. 打开仓库的 **Settings → Pages**
2. **Source** 选 `Deploy from a branch`
3. 分支选 `main`，目录选 `/ (root)`，点 **Save**
4. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

## 技术说明

整个游戏就一个 `index.html` 文件（HTML + CSS + JavaScript 全部内联），
国际象棋规则引擎是自研的，没有引用任何第三方库。
走法生成经过 perft 标准节点数校验（开局 20 / 400 / 8902，Kiwipete 48 / 2039）。
