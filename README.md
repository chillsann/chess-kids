# ♞ 百变棋盘乐园

一个**纯前端、零依赖**的棋盘游戏合集，一个文件里装了三种棋：国际象棋、中国象棋、军棋。
界面、提示、音效、操作方式完全一致，切个游戏就能开玩，适合新手和孩子。

## 三种棋

| 游戏 | 棋盘 | 你执 | 特色 |
| --- | --- | --- | --- |
| ♞ 国际象棋 | 8×8 | 白方 | 王车易位、吃过路兵、兵升变、将军 / 将杀 / 逼和、三次重复判和 |
| 中国象棋 | 10×9 | 红方 | 马走日蹩马腿、象走田塞象眼、炮翻山、兵过河能横走、将帅不能照面、楚河汉界 |
| 军棋 | 6×10 | 红军 | 两国陆战棋明棋：官大压官小，工兵拆雷，炸弹同归于尽，行营里安全，扛走军旗就赢 |

## 玩法模式

| 模式 | 说明 |
| --- | --- |
| 和电脑玩 | 你执先手，电脑执后手，可选**简单 / 中等 / 厉害**三档难度（三棋通用同一套 AI） |
| 和朋友一起玩 | 两人同屏轮流走棋 |

## 怎么操作

- 顶部**游戏按钮**（国际象棋 / 中国象棋 / 军棋）随时切换，每种棋都有自己的规则小卡片
- 点一下自己的棋子 → 再点**绿色圆点**就能走；**粉色圈圈**表示这一步可以吃掉对方棋子
- **给个提示**：小助手推荐一步好棋
- **悔棋** / **翻转棋盘** / **新的一局**：随时可用
- 走路时右侧「小知识」会自动讲解这步棋的规则要点
- 军棋里行营画了⛺，棋子滑到行营里就安全了

## 声音

- **🎹 钢琴曲**：背景音乐是 Web Audio 实时合成的钢琴版《欢乐颂》（C 大调，16 小节循环，正弦泛音堆叠 + 琴槌噪声音色），不加载任何音频文件
- **🔊 音效**：走棋、吃子、将军、炸弹爆炸、胜负等合成音效（三种棋各有各的吃子声）
- 两个开关的状态会记住；iPad / iPhone 侧边静音拨杆会关掉整个网页音频，页面里也有对应提示

## 本地打开

直接双击 `index.html` 就行，**不需要服务器、不需要安装任何东西**。

## 部署到 GitHub Pages

1. 打开仓库的 **Settings → Pages**
2. **Source** 选 `Deploy from a branch`
3. 分支选 `main`，目录选 `/ (root)`，点 **Save**
4. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

## 技术说明

整个游戏就一个 `index.html` 文件（HTML + CSS + JavaScript 全部内联），没有任何第三方库。

- 三种棋各自是一个**游戏模块**（规则 / AI / 棋子样式 / 规则文案），共用同一套渲染、走棋、提示、悔棋、翻转控制器
- AI 是共享的 negamax + α-β 剪枝 + 迭代加深 + 吃子排序，带超时熔断，三个游戏通用
- 国际象棋走法生成经过 perft 标准节点数校验（开局 20 / 400 / 8902，Kiwipete 48 / 2039）
- 中国象棋、军棋规则各有单测覆盖（蹩马腿、塞象眼、炮翻山、过河兵、将帅照面；战斗表、炸弹、行营、夺旗）
- 音频是 Web Audio 实时合成，零音频文件；iOS 上做了静音拨杆解锁处理
